## Лендинг кофейни «Корица»

Статическая страница на HTML/CSS/JS без зависимостей.

- `index.html` — разметка: hero, «О нас», меню, отзывы, контакты и форма обратной связи
- `css/style.css` — стили и адаптив (брейкпоинты 1024 / 860 / 640 px)
- `js/main.js` — меню с фильтром по категориям, мобильная навигация, маска телефона, валидация формы, анимации появления

Запуск: откройте `index.html` в браузере. Отправка формы пока имитируется — для реальной отправки замените `setTimeout` в `js/main.js` на `fetch()` к своему API.
