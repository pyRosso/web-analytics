## Лендинг кофейни «Корица»

Статический сайт на HTML/CSS/JS без зависимостей, 5 страниц:

- `index.html` — главная: первый экран, преимущества, популярные позиции меню
- `about.html` — о кофейне: история, как готовим кофе
- `menu.html` — полное меню с фильтром по категориям
- `reviews.html` — отзывы гостей
- `contacts.html` — адрес, часы работы и форма обратной связи
- `css/style.css` — стили и адаптив (брейкпоинты 1024 / 860 / 640 px)
- `js/main.js` — меню, мобильная навигация, маска телефона, валидация формы, анимации появления

В подвале каждой страницы установлен счётчик LiveInternet (88×31).

Запуск: откройте `index.html` в браузере. Отправка формы пока имитируется — для реальной отправки замените `setTimeout` в `js/main.js` на `fetch()` к своему API.
